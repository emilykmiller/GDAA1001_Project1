# GDAA1001_Project1
The following project is produced in accordance with the requirements of Project 1 of the GDAA 1001 course, a requirement of the GIS-Remote Sensing course at NSCC. This document will cover the building and design of an ETL pipeline for "Notifiable Disease Counts by Rates and Health Zone" and "School-Based Immunization Coverage in Nova Scotia" from years 2014 - 2021 using tidy data principles. Additionally, the data will be visualized on a map of Nova Scotia's four Health Authority Management Zones. The product is unedited, unverified, and intended for educational purposes only.
